# 最新状態

## 現在の版

- アプリ版: `2026.09.08-1`（2026-09-08に本番デプロイ済み・ユーザー報告）
- Sheets APIによる追記、LINEプレビューの版更新・長文保存、種別別の場所継承、削除退避先の容量不足を修正。詳細は[監査修正記録](../../docs/fixes-2026-09-08.md)。
- ソース: 予約後のプラン・人数・料金・顧客情報・日時の一括変更を追加済み
- 管理Webアプリへの反映: 受付GASとともに新バージョンへデプロイ済みとの報告を受領。本番ソースとの直接照合・実サービス上の動作確認は未実施。
- 予約受付GASとの共通変更: 予約一覧を45列へ統一し、管理プランIDを追加（**反映済み**）
- 削除確認: 予約番号の再入力なし・内容を表示する1回確認へ変更済み
- 読み込み: 45秒待機、更新失敗時の既存表示保持、履歴競合防止、列構成と開催場所候補の6時間キャッシュ、初期JSONの重複削減
- 初期表示: `doGet`で取得したJSONをHTMLへ直接埋め込み、初回の`google.script.run`待ちを廃止
- データ補正: U列の`TRUE`/`FALSE`誤表示を除去
- WebサイトのLINE通知API: リトライキー対応を本番デプロイ済み
- 紹介制度: 49列読取・紹介ダッシュボード・予約詳細・手動確定／取消／支払済みを追加
- 満席・重複予約削除: 対応する未払い紹介成果を取消へ連動（支払済みは自動変更せず警告）
