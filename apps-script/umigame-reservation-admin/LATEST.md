# 最新のGAS変更

更新日: 2026-10-31

## 現在の版と本番状況

完全版: [`Code.gs`](Code.gs) — `2026.10.31-3`、**本番版39へ更新済み**（2026-10-31 17:45 JST）。
設定: [`appsscript.json`](appsscript.json)。Google Sheets API v4（識別子 `Sheets`）を保持。

- 大元の集客元と予約経路を分離し、回答／初回計測の根拠を併記。旧フォームの大元は不明。[分離記録](../../docs/dual-attribution-2026-10-31.md)。
- ChatGPT・Claude・Gemini・Perplexity・Copilot・Grok・DeepSeekを媒体名で区別する。[AI別分類の反映記録](../../docs/ai-traffic-sources-2026-10-31.md)。
- 仮予約通知の冒頭に、媒体・掲載場所・紹介者の専用リンク・判定根拠を表示。単品・各セットのメールに適用。[調査・検証・反映記録](../../docs/traffic-source-email-audit-2026-10-31.md)。
- 既存の公開ID・URL・実行者・アクセス設定を維持。保存コードの全文一致とデプロイ成功を確認。370テスト成功。実予約・実メールの送信試験は行っていない。
- 署名付き専用入口から取得した集客経由を、既存49列の末尾AX〜AZへ保存する52列構成。
- そういちろう経由のナイト予定は🥥、通常のナイト予定は🦀。セットプランでもナイト成分のみ切り替える。
- 担当スタッフ・報酬用紹介コードと集客経由を分けて扱う。旧予約の経由は推測で補完しない。
- 2026-09-26に旧本番v34からv36へ更新。2026-10-31にメール表示を改善したv37、AI別分類のv38へ更新。計測・保存の方式は維持している。
- 本番シートの経由3列と署名鍵の設定を確認済み。`setupSheet()`・`setupReferralProgram()`の再実行は不要。

## 検証・運用

2026-09-26の検証では、実サービスの隔離シート・Calendarで8パターンの受付、行保存、予定作成、🥥・🦀を確認。顧客通知0件。検証用のシート・Calendar・一時デプロイは削除済み。2026-10-31は実データの読み取りと外部操作を模擬化した結合テストを実施した。

公開デプロイID、署名鍵の管理場所、専用リンク、ロールバック基準は[公開作業記録](../../docs/booking-source-release-2026-09-25.md)を参照。過去の監査・LINE送信関連の履歴は[`CHANGELOG.md`](CHANGELOG.md)を参照。

`Code.gs`と`Code.next.gs`を同じGASプロジェクトへ両方配置しないでください。未反映変更がある場合だけ`Code.next.gs`を作成します。実際のLINEログインを経由する予約完了と顧客通知の送信試験は今回行っていません。
