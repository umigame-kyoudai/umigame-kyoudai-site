## 現在の版と本番状況

完全版: [`Code.gs`](Code.gs) — `2026.09.08-1`、**2026-09-08に本番デプロイ済み（ユーザー報告）**。
設定: [`appsscript.json`](appsscript.json)。Google Sheets API v4（識別子 `Sheets`）が必要です。

受付・管理の両GASを新バージョンへデプロイしたとの報告を受け、受付側の`Code.next.gs`を内容を変えずに`Code.gs`へ昇格しました。本番ソースとの直接照合・実サービス上の動作確認は未実施です。

- 不正な予約金額・割引額を、シート・カレンダー・通知処理より前に拒否する。
- 新規予約の行追加と値保存をSheets APIで一括実行し、管理GASとの同時追記による予約消失を防ぐ。
- 保存後は予約番号・時間・プラン・金額を再読込し、不一致を成功扱いにしない。
- M/N/S/T等の管理用入力規則を維持し、V列以降の旧チェックボックス規則を除去する。
- 紹介制度`2026.08.24-1`、49列スキーマ、同一予約番号の再送判定も含む。
